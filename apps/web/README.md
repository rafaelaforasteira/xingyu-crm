# Xingyu Web

Next.js 15 (App Router) frontend for Xingyu CRM.

## Scripts

- `pnpm --filter @xingyu/web dev`
- `pnpm --filter @xingyu/web build`
- `pnpm --filter @xingyu/web lint`
- `pnpm --filter @xingyu/web typecheck`
- `pnpm --filter @xingyu/web test`
- `pnpm --filter @xingyu/web test:e2e`

## Env

`NEXT_PUBLIC_API_URL` defaults to `http://localhost:3333`.
