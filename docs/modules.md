# Modules

1. **Dashboard** — KPIs, charts, operational lists with deep-link filters
2. **Inbox** — omnichannel conversation list + composer + contact/deal side panel
3. **Contacts / Companies** — CRUD, filters, merge hooks, timelines
4. **Pipelines & Deals** — multi-funnel Kanban, DealWorkspace with conversation-first UX
5. **Tasks** — commercial routine, overdue highlighting, completion flow
6. **Orders** — items, payments, logistics timeline, status activities
7. **Repurchase / Reactivation** — segmentation + demonstrative scores + opportunity funnels
8. **After-sales** — occurrences with protocol, status workflow, attachments metadata
9. **Automations** — trigger/condition/action builder, executions/logs (basic engine)
10. **Marketing** — campaigns + attribution reports (demo data)
11. **Reports** — commercial, service, productivity, orders, repurchase
12. **Settings** — general, pipelines, custom fields, tags, users, integrations
13. **Search & Notifications** — command palette and in-app alerts
